# Cerulean-Toolkit
一个多功能 (以后就会是的) 工具箱，包含 Phigros 查分等功能

## 安装方式

可通过微软应用商店下载安装

## 推荐运行环境

- 系统：Windows 11 （Windows 10 理论可以）
- 框架：.NET 10 （本应用为 Native AOT 发布，可不安装）

## 开发环境

- 系统：Windows 11 Insider Bata
- 框架：.NET 10
- IDE：Visual Studio 2026 Insider
